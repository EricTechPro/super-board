Commit

The commit message, in the super-board repo and every project it is installed in. Emoji map: ✨ feat · 🐛 fix · 🔧 chore · ♻️ refactor · 🧪 test · ⚡ perf · 📝 docs · 👷 ci · 💄 ui · 🔒 security · ⏪ revert · 🚧 wip. Squash merge = PR title + bullet body.

Short bullets
🐛 [fix] receipts: show a size error over 10 MB

- 413 now shows "File too large"
- client checks size before upload
- e2e covers desktop + mobile

Closes #790
Co-Authored-By: Claude …

Ticket

Problem · Context · Fix · Acceptance criteria · Risk · Blocked by. Context uses one step per line.

Lettered under Where

🐛 [bug] receipts: spinner never stops over 10 MB

Problem

A 12 MB PDF spins forever. The 413 is never handled.

Context

  1. Where: /dashboard/receipts
    1. Sign in as owner
    2. Click Receipts
    3. Drag 12mb.pdf onto the drop zone
  2. Who: any signed-in user

Fix

Map 413 to the size message; check size first.

Acceptance criteria

  • Size message within 1 s
  • No request over 10 MB

Risk

Limit in two places → one constant.

Blocked by

  • None.

Lane comment

The head is [role] [label] status, then what was done, what's left, and who's next. The reviewer report is one comment, edited in place each round. All prose goes through humanizer.

## Writing (super-board)
| Thing  | Format                      |
|--------|-----------------------------|
| title  | `emoji [type] scope: subj`  |

- NEVER put arrows in steps. one per line.
- NEVER link screenshots. embed raw URL.
- DON'T list files in comments.
