The board runs

3 lanes
Buildingsuper-build

Own worktree, smallest safe change, tests, draft PR.

 QAsuper-qa

Evidence, test-gap check, screenshots, or bounce back to Build.

 Reviewsuper-review

Its own review, remembers prior findings, then the merge gate.

Uses: Matt Pocock skills, ponytail, impeccable, humanizer.

Install

In your project folder.

curl -fsSL https://raw.githubusercontent.com/EricTechPro/super-board/main/get.sh | bash

Needs Claude Code, gh, jq, bash 3.2+ and Python 3. The installer checks.

/plugin marketplace add EricTechPro/super-board /plugin install super-board@super-board

The plugin ships the skills only. Run /super-board:super-board onboard; its 🔍 Checks step adds the guard hooks, scripts and workflows.

git clone https://github.com/EricTechPro/super-board.git ./super-board/install.sh [--no-hooks] [--protect-main] /path/to/your-project
Then open Claude Code and run /super-board onboard8 steps · Enter takes the recommended answer · see it first
