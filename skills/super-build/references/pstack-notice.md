# Pstack attribution

The tracing and caller-first design instructions in `decision-policy.md` and
`../../super-board/references/design-preflight.md` adapt pstack's `how`, `why` and
`architect` instructions from `cursor/plugins` commit
`88d47514b82e7c44f00f2b2a72ff6dd12158038c`.

Source: https://github.com/cursor/plugins/tree/88d47514b82e7c44f00f2b2a72ff6dd12158038c/pstack

The adaptation keeps super-board's host-neutral skills, lane ownership and existing
test/review gates. It does not copy Cursor model choices, tool names or orchestration.
